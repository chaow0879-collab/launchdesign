# 单文件交付说明（v8）

本文说明 v8 的**单份 HTML 交付物**如何生成、体积构成、为什么不在仓库里，以及站内 `/download/` 的挂载方式。与 `dist/` 的站点版区分开：`dist/` 不是单文件。

## 一、两种产物，不要混用

| 产物 | 生成命令 | 内容 | 体积 | 用途 |
|---|---|---|---|---|
| **单文件版** | `node build.mjs` | 一份 HTML：模型 base64、26 段配音 base64、story/beats/shots 数据、JS bundle、CSS 全部内嵌 | `out/龙创汽车设计_交互动画_v8.html`，23,563,992 字节（约 22.5 MiB） | 离线交付、`/download/` 下载、客户本地双击打开 |
| **站点版** | `node build.mjs --site` | `index.html` + `model.glb` + `audio/*.mp3` | `out/site/`（部署后为 `dist/`）：HTML 1,522,401 字节（约 1.45 MiB）、车模 8,706,568 字节（约 8.3 MiB）、配音 26 个 mp3 约 7.5 MiB | 在线演示 `https://launch.ailp.fun`，按需加载、可缓存 |

判断依据（源码）：

- `build.mjs:53-58`：单文件版把 `/*__MODEL__*/`、`/*__AUDIO__*/`、`/*__DATA__*/` 全部替换进 HTML。
- `build.mjs:59-77`：站点版把 `model.glb` 写成 `data-src="model.glb"`，配音写成 `audio/<id>.mp3` 的 URL。
- `build.mjs:99-101`：单文件默认输出路径 `out/龙创汽车设计_交互动画_v8.html`。

实测核对（2026-11-12，当前仓库产物）：

- 单文件：`data-src="model.glb"` **0 处**；`"base64"` 字段 **26 个**；`audio-data` 内嵌 JSON 文本 10,467,879 字符（约 10.4 MB）。
- 站点版：`dist/index.html` 内 **26 条** `"url":"audio/<id>.mp3"`，模型为 `data-src="model.glb"`；`dist/model.glb` 与 `dist/audio/*.mp3` 必须同目录存在，单独拷走 `index.html` 无法播放。

## 二、如何生成单文件

前置条件：Node.js 20+，`npm install`（esbuild + three），并准备素材目录：

```
<LC_ASSETS>/
  audio-manifest.json          # 26 个节点的 6 段字幕与时间戳
  assets/audio/<节点id>.mp3     # 26 段配音
  assets/tesla-model-3.glb      # 车模
```

```bash
export LC_ASSETS=/path/to/assets-unpacked
node build.mjs
# → out/龙创汽车设计_交互动画_v8.html
```

说明：

- `build.mjs:9`：`LC_ASSETS` 未设置时回退到 `/home/claude/longchuang-anim/unpacked`，换机器必须设置。
- `build.mjs:15-17`：构建时会校验每个节点恰好 6 段字幕、字幕拼接必须等于 `narration`，不满足直接失败；配音缺失也会失败。
- 构建脚本优先调用 `node_modules/@esbuild/win32-x64/esbuild.exe`，找不到再回退 esbuild JS API（`build.mjs:23-48`）。

## 三、体积构成（约 22.5 MiB）

| 组成 | 约值 | 说明 |
|---|---:|---|
| 车模 base64 | 11.6 MB | `dist/model.glb` 8.3 MiB × 4/3 |
| 配音 base64 | 10.4 MB | 26 段 mp3 共约 7.5 MiB × 4/3 |
| JS bundle | 1.1 MB | `out/app.bundle.js`，Three.js + 业务代码 |
| CSS / HTML 外壳 | 约 0.05 MB | 5 个 CSS 文件拼接 |
| 合计 | 23,563,992 字节 | 实测单文件大小 |

注意：单文件是**单行 HTML**，任何一次车模或配音更新都会让整份文件重写，diff 没有可读性。

## 四、为什么不入库

1. **仓库膨胀**：22.5 MiB 的文本文件进 git 后，每次素材更新都新增一份完整 blob；多迭代几版，clone 和拉取都会明显变慢。
2. **它是构建产物**：`out/` 已在 `.gitignore:3` 排除；源码 + `LC_ASSETS` 才是可维护的输入。
3. **站点版与单文件版同源**：两份产物都来自同一份 `src/` 与 `data/`，发布时用同一个 commit 各构建一次即可，不需要把大文件提交进仓库。
4. 仓库里保留的是 `dist/` 站点版（提交在仓库、服务器直接托管），单文件版按本文第五节走 `/download/` 发布。

## 五、站内 `/download/` 的挂载方式

原则：**不要把单文件放进 `dist/` 让 `caddy static` 顺带托管**——`dist/` 是站点版，单文件应作为独立发布件，避免每次站点部署 `rsync --delete` 把它删掉，也避免 22.5 MB 文件进入站点目录的缓存策略。

### 方案 A（推荐）：独立发布目录 + Caddy `/download/*`

构建机：

```bash
export LC_ASSETS=/path/to/assets-unpacked
node build.mjs
mkdir -p release/download
cp "out/龙创汽车设计_交互动画_v8.html" "release/download/longchuang-v8.html"
scp release/download/longchuang-v8.html root@<host>:/srv/longchuang-download/
```

服务器 Caddyfile（在现有站点配置里加一段，放在站点 `handle` 之前）：

```caddyfile
example.com {
	handle /download/* {
		root * /srv/longchuang-download
		header Content-Disposition "attachment"
		header Cache-Control "public, max-age=3600"
		header X-Robots-Tag "noindex"
		file_server
	}
	handle {
		root * /srv/longchuang-site   # 现有 dist/ 的托管目录
		file_server
	}
}
```

要点：

- 下载文件名建议用 ASCII：`longchuang-v8.html`；中文文件名在 `Content-Disposition` 和 URL 里都要额外编码，容易出错。
- `Content-Disposition: attachment` 让浏览器下载而不是直接打开；如果希望站内直接预览，可去掉这一行。
- `/download/` 是独立 root，**不经过** `dist/` 的构建覆盖。
- 发版建议带版本号（如 `longchuang-v8-20261112.html`）或改 `Cache-Control`，避免客户拿到旧缓存。

### 方案 B（简单）：放进 `dist/download/` 子目录

如果服务器没有独立目录，也可以：

```bash
node build.mjs --site
mkdir -p out/site/download
cp "out/龙创汽车设计_交互动画_v8.html" out/site/download/longchuang-v8.html
# 再按 README 的流程把 out/site 覆盖到 dist/
```

访问 `https://launch.ailp.fun/download/longchuang-v8.html`。前提是部署脚本不是 `rsync --delete` 清空 `dist/`，否则每次发版都要重新拷一次；这也是本文推荐方案 A 的原因。

### 站内入口

在页面里加入下载入口（按现有页面结构，放在 header 工具区或关于弹窗）：

```html
<a class="quiet" href="/download/longchuang-v8.html" download>下载单文件版</a>
```

不要把它做成自动下载或首屏弹窗，避免影响自动播放与移动端布局。

## 六、发布前自检

在构建机对单文件执行（不依赖服务器）：

```bash
f="out/龙创汽车设计_交互动画_v8.html"
ls -l "$f"                                  # 约 23,563,992 字节
grep -c '"base64":"' "$f"                   # 26
grep -c 'data-src="model.glb"' "$f"         # 0
grep -c '"url":"audio/' "$f"                # 0
```

浏览器自检（断网、`file://` 打开）：

1. 打开后无需按播放键，画面自动开始（有声自动播放被拦时先静音播放，点页面开启声音）。
2. 8 个阶段、26 个工序全部可达；每工序 6 个镜头条可点。
3. 拖进度条后画面重建，无上一镜头残留。
4. 播完最后一个工序显示“全程讲解完成”，不循环。

## 七、与 `dist/` 的关系

- `dist/` 继续服务在线演示；`/download/` 只放单文件发布件。
- 两份产物必须来自**同一个 commit**：先 `node build.mjs --site` 更新站点并部署，再 `node build.mjs` 生成单文件上传 `/download/`。
- 如果只更新了单文件而没更新站点，会出现“下载版与在线版内容不一致”；发布记录里同时写两个产物的 commit 与构建时间。
