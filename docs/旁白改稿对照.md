# N 旁白改稿对照

项目 `projects/longchuang-v8`，26 工序 × 6 句 = 156 句。改稿只动 `data/story.json` 的 `narration` 与对应 segment 文本，标题、镜头动作、句数一律未动。

改稿规矩（硬性）：

1. 每句不超过原句字数（逐句对齐，宁可短不可长）。
2. 专业术语当场用大白话解释或直接换掉：曲率→弯得急不急、包络→它占的那块地方、基线→这版定死、硬点→定死不能动的点、点云→一堆测量点、公差→允许多大误差、面差→两个面的高低差。
3. 第 6 句必须落到对车／对下一款车的具体后果，不写"保证可追溯"这类流程话。
4. 不用"不仅…还…""为…提供…""避免…"这类说明书句式，改短句、主谓宾。
5. 工序顺序、专业名、输入输出关系不改。

## 五组对照（最能看出接地气的地方）

**解读电动车需求与目标｜第 4 句**

- 改前（34 字）：续航并不只由电池决定，整车质量、风阻和能量管理，都与同一个目标有关。
- 改后（22 字）：续航不只靠电池大，车重、风阻、电耗都拖后腿。

**刮削精修与光影评审｜第 3 句**

- 改前（36 字）：有方向的刮削轨迹，让材料去除保持连贯，修改逐渐延伸到周围自然过渡的区域。
- 改后（28 字）：顺着一个方向刮，削掉的材料才连得上，改动自然过渡到周围。

**反射线、间隙与工艺校核｜第 2 句**

- 改前（39 字）：截面里能看到厚度、翻边与连接方式，这些条件决定外表面后面是否有足够的工程空间。
- 改后（34 字）：截面里能看到板多厚、边怎么折、怎么连，这决定外表面后面还有没有空间。

**搭建车身骨架与饰件结构｜第 5 句**

- 改前（37 字）：紧固接口不仅要装得上，还要考虑装配工具、维修操作以及异响和松动等使用风险。
- 改后（32 字）：螺栓接口不只要拧得上，工具伸不伸得进去、以后会不会响和松都要想。

**工装定位、样车装配与上电｜第 2 句**

- 改前（36 字）：定位销、支承面与装配基准共同确定零件位置，工装本身也需要经过检查和校准。
- 改后（32 字）：定位销、支承面和装配基准一起把零件卡在位置上，工装自己也得校过。
