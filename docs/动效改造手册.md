# 动效改造手册（v9）

> 每个改造节点的 agent 都读这一份。目标：把"淡入淡出"换成"看得见的因果"。
> 用户原话：「用好动画展示每个动作细节」「工作原理也要用动画展示」。

## 一、判断标准（自检时逐条过）

一个镜头算合格，必须同时满足：

1. **有对象**：画面里至少有一个可以指出来的实体（零件、工具、工装、车身件），不是纯光效。
2. **有因果**：这个对象因为上一个动作而改变，并且改变方式是**连续位移/旋转/形变**，不是透明度变化。
3. **有落点**：位移结束时它**停在一个有意义的位置**（贴合面、卡槽、螺栓孔），用 `K.stopAt()` 保证不穿透。
4. **可回放**：任意 t 采样得到同一状态。禁止 `Math.random()`、`Date.now()`、`performance.now()`。
5. **不改时长**：`beats.json` 与 6 句的时间窗一个字都不能动。

## 二、六个替换套路

| 现在（坏） | 改成（好） | API |
|---|---|---|
| 零件 `position.x` 直线 lerp 到目标 | 沿路径进给，**碰到面就停**，越界只换算成让位 | `K.stopAt(group, curve, stopU, {push, axis, squash})` |
| 螺栓 `rotation.y = k*12`（一次性角度） | `rotation.y = k * Math.PI * 4`（随进度**多圈旋入**） | 直接改表达式 |
| 装配完成靠 `op(obj, 1)` 淡入 | 先位移到位，到位后再给 0.08 的轴向压缩表示"压紧" | 位移 + `scale` |
| 能量/信号用一条 `flow` 从头亮到尾 | `flow` 的 `reach` 跟旁白进度走；断路时 reach 停住 | `K.flow(...)` + `reach` |
| 曲面/载荷"变化"只有热力图层 | `car.setDeformScale(x)` + `setDeformFollow(true)`，车漆跟着变形 | `car.setDeformScale/ Follow` |
| 部件悬空或落地无影 | 落地面/车体面加接触暗影 | `K.shadowPatch(r, opacity)` |

## 三、硬规则

- **只改你负责的节点文件**，`src/engine/*`、`src/scene.js`、`src/app.js`、`src/css/*`、`data/*`、`build.mjs` 一律不动
- 每处改动控制在 **≤ 12 行**，不重构节点结构，不改 `update(t)` 签名与返回
- 不许新增对 `systems.js` 子件名的引用（P 刚换过实现，名字虽然都保留了，但你用旧名以外的东西会脆）
- 位移幅度要"看得见"：1080p 全景机位下 ≤ 0.05m 的变化观众看不到，装配类动作至少要 0.15m 或角度 ≥ 90°
- 缓动：进场用 `ease` 或 `easeOut`，接触前 15% 必须减速（用 `ease` 的尾段自然减速即可）

## 四、自检

```bash
node --check <你改的每个文件>
grep -n "Math.random\|Date.now\|performance.now" <你改的文件>   # 必须为空
```

逐镜头写一张表：`镜头号 / 旁白要点 / 对象 / 动作 / 接触面 / 改动行号`。
